On Windows run certutil -hashfile <file> SHA256. On macOS or Linux run sha256sum <file>.

Windows Defender warning

Defender may flag the Windows client as Trojan:Win32/Wacatac.H!ml. It's a machine-learning false positive: the client downloads helper files and changes routes and DNS, which looks like VPN hijacking.

Check the SHA-256 hash, or run it from source below. See issue #11.

Upgrading from an older version

  • The APK is debug-signed. If Android refuses to install over an older build, uninstall the old one first and re-enter your settings.
  • The APK file name changed from Hotspot_Bypass_VPN.apk to Hotspot-Bypass-VPN.apk.
  • The Windows client now ships as an installer or a portable ZIP instead of a single .exe.

Build from source

Android app

git clone https://github.com/nestchao/Hotspot-Bypass-VPN-Unlimited-Hotspot.git
cd Hotspot-Bypass-VPN-Unlimited-Hotspot
./gradlew assembleDebug

Windows client

cd Hotspot-Bypass-VPN-Unlimited-Hotspot/laptop_proxy
pip install -r requirements.txt
python main.py

Build the standalone package with build_exe.bat.
