FAQ

Frequently asked questions

Can't find your answer? Ask on GitHub and attach the app's debug log.

How is this different from a normal hotspot?

A normal hotspot uses Android's built-in tethering, which carriers can detect and throttle. This app uses a Wi-Fi Direct link and sends traffic through a proxy on the phone, so to the carrier it looks like the phone's own traffic.

Do I need root?

No. Neither the host nor the client phone needs root.

Will it work with my carrier?

It works for most people, but we can't promise every carrier in every country. Detection methods differ.

Is it legal?

Sharing your connection is legal in most countries, but your carrier's terms may forbid tethering. Check them before you use it.

Why does it need location permission?

Android requires it for Wi-Fi Direct. The app never reads your GPS location.

The service stops when I lock the screen

Grant Ignore battery optimization, add the app to the Auto-start or Protected apps list, and lock it in recent apps.

Connected, but pages won't load

Set Private DNS on the client phone to Off or Automatic. If that doesn't help, check the host still shows Service active, then reconnect the VPN.

Can one phone be host and client at once?

No. The app runs one mode at a time and warns you if you try to switch while one is active.

How far apart can the devices be?

Usually 30–50 m with a clear line of sight. Walls shorten the range.

How fast is it?

Usually 10–40 Mbps, depending on the phone's signal, the distance between devices and the band. 5 GHz is faster, 2.4 GHz reaches further.

Is it good for gaming?

Yes. UDP traffic is supported, and it typically adds 30–60 ms on top of the phone's own ping. Use 5 GHz and keep the devices close.

Does streaming work?

Yes. Netflix, YouTube and other streaming services work normally.

Why does Windows need administrator rights?

It creates a virtual network adapter and changes the routing table. Every VPN app on Windows needs this.

Can I use a desktop PC?

Yes, if it has Wi-Fi. A desktop without Wi-Fi can use a USB Wi-Fi adapter.

Does it work on Mac?

The desktop client is Windows only. A Mac can join the network a Windows laptop shares, or set a manual SOCKS5 proxy to 192.168.49.1:8080 for browsing.

Can my PS5 connect straight to the phone?

No. A PS5 can't run the app or use a SOCKS5 proxy, so it goes through a Windows laptop. That adds about 5–15 ms.

Does the laptop need a second Wi-Fi adapter?

Many laptops can stay on the VPN and run a hotspot on one adapter. If yours can't, use a cheap USB Wi-Fi adapter for the hotspot, or an Ethernet cable.

Why is my console's NAT type strict?

Mobile carriers often block incoming connections. Downloads and most games work, but some peer-to-peer games may not.
