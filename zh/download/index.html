Windows Defender 误报

Defender 可能把 Windows 客户端标记为 Trojan:Win32/Wacatac.H!ml。这是机器学习规则的误报：客户端会下载辅助组件、修改路由和 DNS，看起来像 VPN 劫持。

可以用 SHA-256 校验文件，或按下方说明从源码运行。详见 issue #11。

从旧版本升级

  • APK 使用调试签名。如果无法覆盖安装旧版本，请先卸载旧版本，再重新填写设置。
  • APK 文件名从 Hotspot_Bypass_VPN.apk 改为 Hotspot-Bypass-VPN.apk。
  • Windows 客户端现在提供安装包和便携版 ZIP，不再是单个 .exe 文件。

从源码构建

Android App

git clone https://github.com/nestchao/Hotspot-Bypass-VPN-Unlimited-Hotspot.git
cd Hotspot-Bypass-VPN-Unlimited-Hotspot
./gradlew assembleDebug

Windows 客户端

cd Hotspot-Bypass-VPN-Unlimited-Hotspot/laptop_proxy
pip install -r requirements.txt
python main.py

用 build_exe.bat 打包独立程序。
