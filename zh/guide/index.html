使用指南

你要连接什么设备？

先设置主机手机，然后选择要连接的设备。

在有流量的那部手机上操作。

  1. 安装 App

    下载 APK 并打开。如果 Android 提示，允许安装未知应用。

  2. 选择 Wi-Fi 频段

    打开Share (Host)页。打游戏选 5 GHz（延迟更低），设备离得远选 2.4 GHz。

  3. 开启服务

    点 START SERVICE。允许位置、通知，以及忽略电池优化，这样锁屏后服务也不会被关掉。

  4. 记下连接信息

    主机屏幕上会显示这些信息。点击即可复制：

小米、华为、OnePlus 等手机会强制关闭后台应用。请把 App 加入自启动或受保护应用，并在最近任务里锁定它。

遇到问题时

问题解决方法
锁屏后服务停止授予忽略电池优化，并把 App 加入自启动。
其他设备搜不到网络关闭再打开 Wi-Fi，然后重新点 START SERVICE。设备保持在 30–50 米内。
速度慢或卡顿切换到 5 GHz，并让设备靠近一些。

在需要上网的那部 Android 手机上操作，它也安装同一个 App。

  1. 连接主机的 Wi-Fi

    在 Wi-Fi 设置里连接 DIRECT-HotspotBypass，密码 87654321。

  2. 填写主机地址

    打开Connect (Client)页，填写主机 IP 192.168.49.1 和端口 8080。

  3. 开启 VPN

    点 START VPN，并允许 Android 的 VPN 连接请求。状态栏出现钥匙图标即表示已连接。

打不开网页？进入 设置 → 网络 → 私人 DNS，设为关闭或自动。

遇到问题时

问题解决方法
VPN 已连接但打不开网页把私人 DNS 设为关闭或自动，然后点 RECONNECT VPN。
连接经常断开保持在 Wi-Fi Direct 范围内（约 30–50 米），并确认主机仍在运行。
需要更多信息点 App 底部的 Show Debug Logs 查看日志。

适用于带 Wi-Fi 的 Windows 10 / 11 电脑，需要管理员权限。

  1. 安装 Windows 客户端

    运行安装包，或把便携版 ZIP 完整解压后再运行。

  2. 连接主机的 Wi-Fi

    在 Windows 的 Wi-Fi 列表里连接 DIRECT-HotspotBypass，密码 87654321。

  3. 连接 VPN

    在 Phone IP Address 填 192.168.49.1，SOCKS5 Port 填 8080，然后点 Connect VPN。首次运行会自动下载 wintun 和 tun2socks，等待显示 Connected。

Windows Defender 可能误报为 Wacatac.H!ml。这是误报，详情见下载页面。

遇到问题时

问题解决方法
提示需要管理员权限右键点击 App，选择以管理员身份运行。
连接后没有网络点 Disconnect，再点 Connect VPN。确认手机仍在分享。
虚拟网卡没有创建以管理员身份运行，并关闭其他 VPN 软件。

游戏主机和电视需要通过已连接的 Windows 电脑上网。请先完成 Windows 的设置。

  1. 在电脑上开启共享

    VPN 显示 Connected 后，在Share with consoles & devices中选择 Wi-Fi Hotspot 或 Ethernet Cable，点 Start Sharing Network。使用网线时，先插好网线并点 Refresh。

  2. 连接游戏主机

    连上 App 中显示的热点名称和密码，或插上网线。IP 和 DNS 设为自动，代理设为不使用。

  3. 测试连接

    运行主机的网络测试，然后试试下载和联机游戏。

断开 VPN 之前，先点 Stop Sharing Network。停止共享时，App 会恢复你原来的 Windows 共享设置。

遇到问题时

问题解决方法
热点无法开启部分无线网卡在连着手机时无法再开热点。请改用网线或 USB 无线网卡。
游戏主机获取不到 IP停止共享后重新开启，再重新连接主机。
提示共享已被占用已有其他网卡在共享网络，请先在 Windows 中关闭它。
能下载但联机游戏进不去运营商可能拦截入站流量，NAT 类型会显示为严格（Type 3）。
