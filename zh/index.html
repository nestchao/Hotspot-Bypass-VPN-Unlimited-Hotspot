通过 Wi-Fi Direct + SOCKS5 代理绕过运营商热点限制。将手机网络分享给笔记本、游戏主机和其他设备 —— 运营商无法检测到热点共享。

Wi-Fi Direct 热点

创建点对点直连而非运营商可检测的移动热点。运营商看到的只是普通手机数据流量，而非热点共享。

🔄

双模式切换

在 Host（分享）模式和 Client（连接）模式之间自由切换。一个应用，两种角色。

💻

Windows 桌面客户端

功能完整的 Windows 应用，使用 TUN 虚拟网卡将全部流量通过手机代理转发，非常适合游戏场景。

🎮

游戏主机 & 电视支持

通过 Windows 网络桥接将连接分享给 PS5、Xbox、Nintendo Switch、Mac 和智能电视。

🔒

无需 Root

完全基于 Android 标准的 VPNService 和 Wi-Fi Direct API 实现，无需 Root 权限。

⚡

持久连接

前台服务搭配 WakeLock、WifiLock 和自动重启机制，即使锁屏也能保持连接不断。
