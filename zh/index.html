功能

为日常上网和打游戏而设计

不用 Root，不用账号，不用付费。

Wi-Fi Direct 共享

手机之间点对点直连，不使用系统热点功能。

支持 UDP 游戏

Roblox、Discord 语音等实时流量都能正常工作，MTU 针对游戏优化。

多设备同时连接

Android 和 Windows 设备可同时连接，一台设备不会占满所有连接。

锁屏也不掉线

前台服务和 WakeLock 让主机在锁屏或划掉 App 后继续运行。

电脑全局 VPN

TUN 虚拟网卡接管所有流量，游戏和应用无需单独设置代理。

无需 Root

只使用 Android 标准 VpnService 和 Wi-Fi Direct 接口。

工作原理

一部手机有流量，所有设备都能上网。

主机手机开启 Wi-Fi Direct 网络和本地代理。其他设备连上后，所有流量都经由这部手机发出。

  1. 主机手机开始分享

    在有流量的手机上点 START SERVICE，它会建立名为 DIRECT-HotspotBypass 的 Wi-Fi Direct 网络。

  2. 其他设备加入

    Android 手机和 Windows 电脑连上这个 Wi-Fi，再开启 App 里的 VPN，所有流量都会经过主机。

  3. 电脑再分享出去

    PS5、Xbox、Switch 和电视装不了 App，可以通过 Windows 电脑的热点或网线上网。

常见问题

快速解答

它和普通的手机热点有什么不同？

普通热点使用 Android 的系统共享功能，运营商可以识别并限速。本 App 使用 Wi-Fi Direct 点对点连接，并通过手机上的代理转发流量，在运营商看来就是这部手机自己在上网。

需要 Root 吗？

不需要。主机和客户端手机都不需要 Root。

对我的运营商有效吗？

大多数情况下可以，但我们无法保证所有国家和运营商都有效，检测方式各不相同。
