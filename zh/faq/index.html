常见问题解答

没找到答案？在 GitHub 上提问，并附上 App 的调试日志。

它和普通的手机热点有什么不同？

普通热点使用 Android 的系统共享功能，运营商可以识别并限速。本 App 使用 Wi-Fi Direct 点对点连接，并通过手机上的代理转发流量，在运营商看来就是这部手机自己在上网。

需要 Root 吗？

不需要。主机和客户端手机都不需要 Root。

对我的运营商有效吗？

大多数情况下可以，但我们无法保证所有国家和运营商都有效，检测方式各不相同。

这样做合法吗？

在大多数国家，分享自己的网络是合法的，但运营商的服务条款可能禁止热点共享。使用前请先查看条款。

为什么需要位置权限？

Android 规定使用 Wi-Fi Direct 必须授予位置权限。App 不会读取你的 GPS 位置。

锁屏后服务就停了？

请授予忽略电池优化，把 App 加入自启动或受保护应用列表，并在最近任务中锁定它。

已连接但打不开网页

把客户端手机的私人 DNS设为关闭或自动。如果仍不行，确认主机仍显示服务运行中，然后重新连接 VPN。

一部手机能同时当主机和客户端吗？

不能。App 同一时间只运行一种模式，切换时会提示你。

设备之间能离多远？

在无遮挡的情况下一般是 30–50 米，墙壁会缩短距离。

速度能有多快？

一般在 10–40 Mbps，取决于手机信号、设备距离和频段。5 GHz 更快，2.4 GHz 覆盖更远。

适合打游戏吗？

适合。支持 UDP 流量，延迟一般比手机本身增加 30–60 ms。请选 5 GHz 并让设备靠近。

能看视频吗？

可以。Netflix、YouTube 等视频服务都能正常使用。

为什么 Windows 需要管理员权限？

客户端要创建虚拟网卡并修改路由表，Windows 上所有 VPN 软件都需要这样做。

台式电脑能用吗？

可以，只要有 Wi-Fi。没有 Wi-Fi 的台式机可以用 USB 无线网卡。

支持 Mac 吗？

桌面客户端只支持 Windows。Mac 可以连接 Windows 电脑共享出来的网络，或者手动设置 SOCKS5 代理 192.168.49.1:8080 用于浏览网页。

PS5 能直接连手机吗？

不能。PS5 无法运行 App，也不支持 SOCKS5 代理，需要通过 Windows 电脑中转，延迟大约增加 5–15 ms。

电脑需要额外的无线网卡吗？

很多电脑可以用同一张网卡同时连 VPN 和开热点。如果不行，买一个便宜的 USB 无线网卡专门开热点，或者直接用网线。

为什么主机的 NAT 类型是严格？

运营商通常会拦截入站连接。下载和大多数游戏可以正常使用，但部分点对点联机游戏可能受影响。
