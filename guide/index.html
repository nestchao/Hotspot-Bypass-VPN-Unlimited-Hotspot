Setup guide

What do you want to connect?

Start with the host phone, then pick the device you're connecting.

Do this on the phone that has the mobile data.

  1. Install the app

    Download the APK and open it. If Android asks, allow Install unknown apps.

  2. Pick a Wi-Fi band

    Open the Share (Host) tab. Choose 5 GHz for gaming (lower lag) or 2.4 GHz if devices are far away.

  3. Start the service

    Tap START SERVICE. Allow location, notifications and ignore battery optimization, so the service keeps running with the screen off.

  4. Note the connection details

    The host screen shows these values. Tap any of them to copy:

Xiaomi, Huawei and OnePlus phones close background apps aggressively. Add the app to Auto-start or Protected apps and lock it in recent apps.

If something goes wrong

ProblemWhat to do
Service stops when the screen turns offGrant Ignore battery optimization and add the app to Auto-start.
Other devices can't see the networkTurn Wi-Fi off and on, then tap START SERVICE again. Keep devices within 30–50 m.
Slow or laggySwitch to 5 GHz and move the devices closer together.

Do this on the Android phone that needs internet. It runs the same app.

  1. Join the host's Wi-Fi

    In Wi-Fi settings, connect to DIRECT-HotspotBypass with password 87654321.

  2. Enter the host address

    Open the Connect (Client) tab. Enter host IP 192.168.49.1 and port 8080.

  3. Start the VPN

    Tap START VPN and accept Android's VPN request. A key icon in the status bar means you're connected.

Pages won't load? Go to Settings → Network → Private DNS and set it to Off or Automatic.

If something goes wrong

ProblemWhat to do
VPN connects but nothing loadsSet Private DNS to Off or Automatic, then tap RECONNECT VPN.
Connection dropsStay within Wi-Fi Direct range (about 30–50 m) and check the host is still running.
Need more detailOpen Show Debug Logs at the bottom of the app.

For Windows 10 or 11 laptops and PCs with Wi-Fi. Needs administrator rights.

  1. Install the Windows client

    Run the installer, or fully extract the portable ZIP before running it.

  2. Join the host's Wi-Fi

    Connect to DIRECT-HotspotBypass from the Windows Wi-Fi list, with password 87654321.

  3. Connect the VPN

    Enter Phone IP Address 192.168.49.1 and SOCKS5 Port 8080, then click Connect VPN. The first run downloads wintun and tun2socks automatically. Wait for Connected.

Windows Defender may flag the app as Wacatac.H!ml. It's a false positive. See the Download page for details.

If something goes wrong

ProblemWhat to do
"Administrator privileges required"Right-click the app and choose Run as administrator.
No internet after connectingClick Disconnect, then Connect VPN again. Check the phone is still sharing.
Virtual adapter not createdRun as administrator and turn off other VPN software.

Consoles and TVs go online through a connected Windows laptop. Finish the Windows steps first.

  1. Start sharing on the laptop

    Once the VPN shows Connected, go to Share with consoles & devices, pick Wi-Fi Hotspot or Ethernet Cable, and click Start Sharing Network. For Ethernet, plug in the cable and click Refresh first.

  2. Connect the console

    Join the hotspot name and password shown in the app, or plug in the cable. Set IP and DNS to Automatic and the proxy to Off.

  3. Run the connection test

    Run the console's network test, then try a download and an online game.

Click Stop Sharing Network before you disconnect the VPN. The app restores your Windows sharing settings when it stops.

If something goes wrong

ProblemWhat to do
Hotspot won't startSome Wi-Fi adapters can't run a hotspot while connected to the phone. Use an Ethernet cable or a USB Wi-Fi adapter.
Console gets no IP addressStop and start sharing again, then reconnect the console.
"Sharing already in use"Another adapter already shares a connection. Turn that off in Windows first.
Downloads work but a game can't joinCarriers may block incoming traffic, so NAT can show as Strict (Type 3).
