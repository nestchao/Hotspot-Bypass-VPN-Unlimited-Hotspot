Features

Built for everyday browsing and for gaming

No root, no account, no subscription.

Wi-Fi Direct sharing

A direct phone-to-device link instead of Android's built-in hotspot.

UDP for games

Roblox, Discord voice and other real-time traffic work. MTU is tuned for games.

Many devices at once

Android and Windows clients connect together, and one busy device can't hog the host.

Stays on when locked

A foreground service and wake lock keep the host running with the screen locked or the app swiped away.

Full VPN on Windows

A TUN adapter captures all traffic, so games and apps need no proxy settings.

No root needed

Uses only the standard Android VpnService and Wi-Fi Direct APIs.

How it works

One phone has the data. Everything else rides on it.

The host phone opens a Wi-Fi Direct network and a local proxy. Devices that join send all their traffic out through that phone.

  1. The host phone starts sharing

    Tap START SERVICE on the phone with data. It opens a Wi-Fi Direct network named DIRECT-HotspotBypass.

  2. Other devices join

    Android phones and Windows laptops join that Wi-Fi, then turn on the VPN in the app. All their traffic goes through the host.

  3. The laptop passes it on

    PS5, Xbox, Switch and TVs can't run the app, so they connect through the Windows laptop's hotspot or an Ethernet cable.

FAQ

Quick answers

How is this different from a normal hotspot?

A normal hotspot uses Android's built-in tethering, which carriers can detect and throttle. This app uses a Wi-Fi Direct link and sends traffic through a proxy on the phone, so to the carrier it looks like the phone's own traffic.

Do I need root?

No. Neither the host nor the client phone needs root.

Will it work with my carrier?

It works for most people, but we can't promise every carrier in every country. Detection methods differ.
